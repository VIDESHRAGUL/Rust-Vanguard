# Rust-Vanguard Installation Guide

This guide will walk you through the process of setting up and running the Rust-Vanguard project on your local machine.

## Prerequisites

Before you begin, make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or later)
- [npm](https://www.npmjs.com/) (comes with Node.js)
- [Rust](https://www.rust-lang.org/tools/install) (for compiling the anti-cheat core)
- [wasm-pack](https://rustwasm.github.io/wasm-pack/installer/) (for compiling Rust to WebAssembly)
